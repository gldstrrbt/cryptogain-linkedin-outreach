General Rule:
- When detecting/monitoring/observing for text or class names make sure to always set the text/class names to lowercase 
- When logging to the CSV log file, please DO NOT modify the cases of the text being written to the CSV file.
- When logging profile URLs/HREFs, only log the part before the "?"  

Part I:
0. open csv log file to read from if it exists, otherwise create one to log to
1. use nodriver python library to open linkedin
2. sign in
3. go to each link in given array. For example:
	["https://www.linkedin.com/company/coindesk/people/"]
4. wait for page to load then scroll to the bottom and/or find and click "show more results" button at the bottom of the page. Add a delay in between loads or add a monitor/observer to wait until the "show more results" button appears again, and a timeout for the montior/observer in case the button does not appear again. 
5. once "show more results" button can no longer be detected, scan each <li> for class name "org-people-profile-card__profile-card-spacing"
6. log each of these <li> elements' content for <button> with a class name "artdeco-button"
7. if a <button> with a class name "artdeco-button" is detected, then check to see if the rest of the contents in the <li> contain any of the words in the following array:
	["reporter", "freelance", "writer", "writing", "journalist", "anchor", "marketing", "marketer", "market analyst", "media relations", "public relations", "outreach", "editor", "community", "partnerships"]
8. if any of the words from that array are detected in the text content (not the HTML attributes of the elements within the <li>), then if the user's info hasn't been logged to the csv log file (use their url as the unique id to check against), log the href/link to their profile one time along with their position title, name, and company, along with False for "sent_connection" column and False for "connected" column for their csv row's entry to the csv log
9. close csv log

Part II:
0. open csv log to read from if it exists.
1. use nodriver python library to log into linkedin if it's not already logged in
2. go to each URL/HREF in each row other than the CSV header (if there is a header) if the row's column for "sent_connection" hasn't been set to True.
3. wait for the URL/HREF's page to load, then check the HTML contents of the page to detect whether or not there's a <button> element containing the text "pending", "connect", or "follow".
4. if "pending" is detected, write to that row's "sent_connection" column True if it hasn't been in the csv log.
	- if "connect" is detected, click it and wait for it to change to "pending" and set a timeout/delay as a fallback to ensure it's been properly sent/requested.
	- if "follow" is detected, detect whether or not a sibling of the button is an element with the class name "artdeco-dropdown" and if a child/grandchild/etc element within it contains a button with the text (not attributes) "more".
		- if "more" is detected then click that button, there should be a div containing <li> elements. Search each <li> to detect whether or not "connect" (not "remove connection") is detected in the text content (not attribute).
			- if "connect" (not "remove connection") is detected, then click that <li> that contains the text "connect" and wait for a button to appear in the page that contains the text "send without a note", then click the button containing the text "send without a note" and wait a moment for the button to disappear but add in a fallback timeout to ensure enough time has passed to move on just in case the button does not disappear. After please log True to the row's "sent_connection" column in the CSV log file. 
5. separately from detecting "pending", "connect", and "follow", please click the "more" dropdown button to detect if any of the <li> elements in the dropdown <div> contain the text "remove connection".
	- if "remove connection" is detected set the row's column "connected" to True in the csv log file
6. please add realistic delays in between actions to avoid getting rate limited or trigger bot detection.
